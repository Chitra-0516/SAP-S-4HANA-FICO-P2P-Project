SAP S/4HANA 2023 - FICO P2P Project

## Project Overview
This project demonstrates the Procure-to-Pay (P2P) business process in SAP S/4HANA 2023.

## Project Objective
To understand and document the end-to-end procurement and vendor payment process using SAP S/4HANA.

## SAP Environment
- ERP: SAP S/4HANA
- Version: SAP S/4HANA 2023
- Module: SAP FICO
- Process: Procure-to-Pay (P2P)

## Project Scope
1. Organizational Structure
2. General Ledger Configuration
3. Vendor Master Data
4. Purchase Requisition
5. Purchase Order
6. Goods Receipt
7. Invoice Verification
8. Vendor Payment
9. Financial Reporting

## Learning Outcomes
- Understand the P2P cycle.
- Learn SAP FICO integration with MM.
- Practice business transactions.
- Document project activities.
